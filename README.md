# Radar de Apuestas (celular)

App web instalable que analiza cuotas de muchas casas de apuestas (The Odds API) y estadísticas
de los equipos (API-Football) para estimar la probabilidad de cada opción en fútbol, tenis y básquetbol.

- Ábrela en Chrome para Android y toca **Agregar a la pantalla de inicio**.
- Las claves, el historial y las estadísticas se guardan solo en el teléfono (almacenamiento del navegador).
  Este repositorio no contiene datos personales.

Ninguna apuesta es segura. Apuesta solo dinero que puedas perder.
